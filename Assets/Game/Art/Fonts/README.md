# Menu font

HOne Menu Sans is a subset of Noto Sans SC (Google / Adobe, SIL Open Font License 1.1; LICENSE.txt). Source: https://github.com/google/fonts/tree/main/ofl/notosanssc (NotoSansSC[wght].ttf).

Derived with tools/m2/prepare_font.py (local tooling), fontTools 4.46.0, regular weight 400, current game/authoring strings and ASCII on 2026-11-10. Source and output SHA-256 are in manifest.json. Rebuild the subset when adding Chinese glyphs. Existing uGUI Text is retained to match the project's menus. This is a technical font integration, not final UI art acceptance.
